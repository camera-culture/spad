The ams and ST sensors sit in the same location relative to the RealSense, so one calibration covers both. The sensor face sits flush with the RealSense optical plane.

ST optical midpoint is exactly Z −9.150 (symmetric package).

TMF midpoint is Z −9.2165 (Tx −10.408, Rx −8.025), 66.5 µm off the line and negligible.

RealSense 50 mm stereo baseline, 15 mm Left-IR→RGB. Rear M3 holes at (106.2, −4.15) and (106.2, −49.15).

Software

spad_capture →

One Python package captures per-zone histograms from both sensors, with a live web dashboard, optional RealSense capture and a single storage format per run.

spad stST VL53L8CHPer-zone histograms over a configurable distance window, on a 4×4 or 8×8 grid.
spad tmfams TMF8828Per-zone time-of-flight counts from predefined or user-defined SPAD masks.

Quick start

For a one-click setup, download the SPAD App.

Download for Mac Download for Windows
Or from the command line
git clone https://github.com/NikhilBehari/spad_capture.git cd spad_capture conda env create -f environment.yml conda activate spad_capture pip install -e . spad st flash # or: spad tmf flash spad st capture --viz # live dashboard at http://127.0.0.1:8888
01

Install

Create the conda environment, install the package, then flash your board.

conda env create -f environment.yml conda activate spad_capture pip install -e . spad st flash # NUCLEO-F401RE + X-NUCLEO-53L8A1 spad tmf flash # Arduino + TMF8828
02

Capture

Defaults: 4×4 zones, 0–2 m, 10 frames for the ST; 3×3 wide, long range, 10 frames for the TMF. Flags override any config passed with -c.

spad st capture spad st capture --start-mm 200 --end-mm 1200 --freq 15 spad st capture -c configs/st/8x8.yaml spad tmf capture --zone 4x4_wide --range short -n 20
03

Live dashboard

Add --viz to any capture to watch data stream in at http://127.0.0.1:8888. Saved runs replay through the same dashboard.

spad st capture --viz spad st viz --source outputs/<run>/data.npz
04

Selecting zones

The ST takes a rectangle on its fixed grid: --zone ROW,COL for one zone or --roi for a block. Fewer zones free on-device memory for more bins over a longer window. The TMF takes a per-pixel mask authored in YAML, so zones can be any shape.

spad st capture --zone 2,2 --end-mm 4000 spad st info -c configs/st/8x8.yaml # bins and budget before capturing spad tmf capture --mask configs/tmf/masks/four_center_quads.yaml
05

RealSense

--rgb --save-depth --ir-left --ir-right records colour, depth and IR alongside each capture. spad camera check reports whether the camera is usable. The binding comes from pip on Linux and Windows and from conda-forge on macOS; capture on macOS needs sudo.

pip install -e '.[rgb]' # Linux, Windows conda install -c conda-forge pyrealsense2 # macOS spad st capture --rgb --save-depth
06

Saved captures

Each run writes to outputs/<run>/: metadata.json, the resolved config.yaml, and one data file (npz for the ST, pkl for the TMF; switch with -f). Every format loads to the same shape.

from spad_capture.storage import load meta, frames = load("outputs/<run>/data.npz") frames[0]["histogram"] # (H, W, num_bins) meta["sensor_layout"]["bin_centers_mm"]
